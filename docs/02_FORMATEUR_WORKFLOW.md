# Workflow Formateur

## Organisation recommandée

Repository public/étudiant :
`SDA-Academy-SQL-Data-Analyst`

Repository privé :
`SDA-Academy-SQL-Corrections`

Le repo privé contient les corrections, solutions SQL et barèmes.

## Déroulement d'une mission

1. Le formateur ouvre un ticket.
2. Chaque apprenant crée sa branche.
3. L'apprenant explore PostgreSQL.
4. Il développe son SQL.
5. Il documente ses résultats.
6. Il pousse sa branche.
7. Il ouvre une Pull Request.
8. Le formateur review.
9. L'apprenant corrige.
10. Merge dans `main`.

## Barème suggéré /20

- Compréhension du problème métier : 4
- Qualité SQL : 6
- Exactitude des résultats : 4
- Interprétation business : 3
- Git/GitHub/documentation : 3
